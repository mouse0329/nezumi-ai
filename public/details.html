DETAILS

ネズミAIの概要

ここには、以前トップページの「構造の設計図」の前に置いていた説明をまとめています。 オンデバイス推論、対応バックエンド、チャット機能、動作要件をひと通り確認できます。

Overview

すべてデバイスの中で完結する

ネズミAIはサーバーにデータを送信しない設計を重視しています。 推論から会話履歴の管理まで、ローカル側で扱える体験を目指しています。

完全オフライン志向

ローカル推論を中心に、プライバシーを優先して使える構成です。

マルチバックエンド

  • LiteRT-LM: Gemma 4 / Gemma 3n
  • llama.cpp: GGUFモデル
  • Web版: WebGPU / WASM

チャット機能

  • リアルタイムストリーミング表示
  • テキストと画像の入力
  • 会話履歴の保存

Features

Android版とWeb版の機能

Android版はネイティブ機能や端末バックエンドを活かし、Web版はブラウザですぐ試せる導線として使えます。

画像生成

  • MNN CPU/OpenCL フォールバック（GPU/NPU を活用）
  • ユーザー承認制のツール呼び出し

エージェント機能

  • アラーム
  • フラッシュライト
  • Web検索 / 天気

自動切り替え

GPU推論を優先し、非対応端末ではCPUへフォールバックする構成です。

Architecture

構造の設計図

Jetpack Composeを中心にClean Architectureで構成し、エンジン層は交換可能な設計です。 

[ UI Layer ]          Jetpack Compose / StateFlow
      ↓
[ ViewModel ]         状態管理 / コルーチン
      ↓
[ Repository ]        Room DB（チャット履歴）
      ↓
[ UseCase / Inference Layer ]
      ↓
[ Engine Layer ]
  ├── LlmEngine      LiteRT-LM（メイン）/ llama.cpp（GGUF）
  └── SdEngine       MNN - Stable Diffusion 1.5

Requirements

動作要件

LiteRT-LMを安定して動かすにはAndroid 13以降を推奨します。Web版はChrome / Edgeなどのモダンブラウザを推奨します。

項目 最小 推奨
Android バージョン 12 / API 30 14+ / API 34+
RAM 6 GB 8 GB 以上
ストレージ空き容量 4 GB 8 GB 以上
GPU / LLM推論 任意 Mali / Adreno 推奨
GPU / 画像生成 OpenCL対応 Snapdragon NPU
Tensor G3搭載端末では、LLM推論はGPUバックエンドで動作する場合がありますが、 画像生成のQNNバックエンドはSnapdragon向けです。Tensor端末ではMNN CPU/OpenCLフォールバックを想定します。
