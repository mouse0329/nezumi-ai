Features

アプリと同じ感覚で使える Web 版

Web版チャット UI と同じ配色、余白、ボタン感に揃えました。 Android版への導線も残しつつ、ブラウザ版を最初に試せる構成です。

オンデバイス推論

モデルをブラウザ側に保存し、会話をローカルで処理します。

WebGPU / WASM

環境に応じて高速寄り、互換性寄りのバックエンドを選べます。

履歴と設定

チャット履歴、モデル管理、テーマなどを Web 版の設定から扱えます。

Requirements

動作要件

Web版はモダンブラウザで利用できます。大きなモデルを扱うため、空きストレージとメモリに余裕がある環境を推奨します。

Web版Chrome / Edge 推奨
バックエンドWebGPU / WASM
モデルGemma 4 E2B / E4B
Android版Android 12 以上

ブラウザで試す

セットアップ画面でバックエンドとモデルを選ぶと、すぐチャット画面へ進めます。
