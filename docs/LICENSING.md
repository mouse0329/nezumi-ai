このプロジェクト（コアロジック）は **LGPL v3 ＋ 独自の商用ライセンス** のデュアル構成で配布しています。外部コードを追加する際は、以下の方針を確認してください。

## 基本方針

- 商用ライセンスも提供する構成のため、**非営利限定のライセンス（CC BY-NC 系など）が付与された外部コード・モデル・アセットは組み込まない**。
- MIT / Apache-2.0 / BSD など、商用利用可能な寛容ライセンスの外部コードは、NOTICE への記載を条件に利用可能。
- LGPL / GPL 系の外部コードを組み込む場合は、リンク方式（静的/動的）によって波及範囲が変わるため、追加前に Issue で相談すること。

## 経緯（参考）

画像生成エンジン（Nezumi Kiln）は、開発初期に `xororz/local-dream`（MNN版 stable-diffusion.cpp、**CC BY-NC 4.0**）をバイナリとしてラップして利用していました（`LocalDreamModule`）。しかし CC BY-NC 4.0 は非営利利用に限定されており、このプロジェクトの商用ライセンス方針と両立しないと判断したため、MNN を直接利用した自前実装（`mnn-sd-engine`）に置き換えました。

このような判断は今後も必要になる可能性があるため、外部コードを追加する際は必ずライセンスを確認し、不明な場合は Issue で相談してください。
