# Nezumi AI v2.4.0 リリースノート

**リリース日:** 2026年10月19日

Nezumi AI v2.4.0 をリリースしました。

このバージョンでは、GGUF 推論基盤の llama.cpp 直結化と GPU バックエンド対応、推論エンジンのプロセス分離、Mini App の実行基盤と SDK、テレメトリの改善、Qwen3-TTS 音声合成に加え、プリセットのインポート・エクスポート機能を追加しました。

## プリセットの共有

* プリセットを `.nzaip` ファイルとしてエクスポートし、別の端末やユーザーと共有できるようになりました
* `.nzaip` ファイルからプリセットを新規登録できるようになりました
* 有効なユーザー定義スキルはファイル内容を含めて書き出し、インポート時に復元します
* MCP サーバー ID やメモリ設定など、端末固有の設定はエクスポート対象から除外します
* プリセット一覧に「読み込み」と各プリセットの「エクスポート」操作を追加しました

## セッションの共有

* チャットセッションを `.nzai` ファイルとしてエクスポートし、ファイルからインポートできるようになりました
* セッションの会話内容や関連情報をファイルにまとめ、バックアップや端末間の移行に利用できます

## モデル対応と推論設定

* Granite 4.2、Qwen 3.8 系、MiniCPM5 などのモデルに向けて、Thinking 制御やツール呼び出し形式の解析を強化
* モデルのメタデータに基づいて常時 Thinking モデルをより厳密に判定
* 推論時の Thinking effort を設定できるようになり、モデルやチャットテンプレートに応じた制御を追加
* Qwen3.5 系のマルチモーダル入力に関する設定と互換性を改善
* 推論設定を初期状態に戻す操作を追加し、マルチモーダルプロジェクターの GPU 利用設定にも対応
* モデルのロード前に GGUF / LiteRT-LM のメモリ要件を推定し、設定画面で確認できるようになりました
* GGUF のロード進捗、明示的なチャットテンプレート、コンテキスト使用量の表示を改善

## チャットと設定画面

* プリセット選択画面を追加し、モデル上書きやピン留めを含むプリセット管理を改善
* 設定検索から該当項目へ移動して強調表示できるようになりました
* サイドバーを統合し、セッション切り替え後の表示状態やキャッシュの同期を改善
* 音声録音ボタン、メディアプレビュー、フォント事前読み込みなど、チャット画面の操作性と表示性能を改善
* iOS アプリの初期構成を追加

## 推論の安定性

* ツール呼び出し後の再試行、未完了応答の扱い、ツールタグの解析を改善
* ストリーミングをバッチ処理し、Binder の詰まりや LiteRT-LM の応答欠落を抑制
* リモート推論プロセス切断時のハングを防ぎ、モデルのロード・アンロードにタイムアウトを追加
* ロード失敗時にメモリ不足などの理由を識別して、より具体的なエラーを表示
* セッション切り替え時の停止や古いコンテキストの表示など、チャット状態に関する不具合を修正

## 新機能

### llama.cpp と推論エンジン

* `rn-llama` を経由せず、本家 llama.cpp と JNI ブリッジで直接接続する構成へ移行
* llama.cpp のサブモジュール管理とビルド時のリビジョン表示に対応
* GGUF 推論で CPU、OpenCL、Vulkan の GPU バックエンドを選択可能にし、利用可否の検出とフォールバック通知を追加
* 端末の状態に応じて推論スレッド数の上限を動的に調整
* GGUF / LiteRT-LM 推論エンジンを別プロセスで実行する AIDL ベースの接続とリモートアダプターを追加
* `ai.unloadModel` API で、GGUF モデル使用後に LiteRT-LM のリソースを強制解放できるよう改善
* LiteRT-LM を 0.17.0 に更新

### Mini App と WebView

* Mini App Runner を追加し、インストール済み Mini App を WebView で実行可能に
* Mini App SDK の権限管理、初期化、RPC、HTTP サーバー連携を実装
* WebView の Document Start API とファイル選択に対応
* Mini App からモデルストレージへアクセスする際の制限とダウンロード API の利用を明確化
* Qwen3 Voice Studio の Mini App サンプルを追加
* Mini App から画像コンテンツチェッカーのモデルをダウンロードして推論できるサンプルを追加

### 音声とマルチモーダル推論

* Qwen3-TTS 音声合成とデバッグ用 UI を追加
* 音声履歴の管理と音声モデルの削除に対応
* コンテキストメーターが実際のトークン使用量を保持し、チャットセッションをまたいで正確な値を表示できるよう改善
* `kvUnified` パラメーターを追加し、画像処理を改善
* ONNX セッションのバックエンド選択と `createTensor` の処理を強化

### テレメトリとプライバシー

* オンデバイス推論でもクラウドモデルと同じ同意条件でテレメトリを送信可能に
* テレメトリの同意画面にクラッシュレポート、パフォーマンス計測、診断情報のカテゴリを追加
* ユーザー由来の内容がログへ出力されないよう改善
* Sentry DSN をリポジトリへ含めず、設定された場合だけテレメトリを初期化する構成に変更

## 不具合修正と改善

* シークレットモードでのセッション切り替え時に、画面とセッション状態が同期しない問題を修正
* GPU バックエンドが利用できない端末で、推論設定と通知が不整合になる問題を修正
* 推論エンジンの構造を整理し、モデルのロード・アンロードとストリーミング処理の安定性を改善
* Android WebView、OkHttp SSE、EncryptedSharedPreferences などの依存関係を更新
* `llama.rn` 依存を削除し、llama.cpp の直接統合へ移行
* `:gguf` / `:litert` プロセスがモデルロード中に OOM Kill されると、メインプロセス側が
  検知できずに読み込み中のまま無期限にハングする問題を修正。`loadModel` / `unloadModel`
  にタイムアウトを追加し、リモートプロセスの切断を即座にエラーとして呼び出し元へ伝播
* Android 11 (API 30) 以降の端末で、リモート推論プロセスの終了理由を
  `ActivityManager.getHistoricalProcessExitReasons` から取得し、メモリ不足による
  強制終了だった場合はユーザーへ「メモリ不足の可能性があります」という具体的な
  エラーメッセージを表示するよう改善
* GGUF モデルのロードに失敗した際、非対応アーキテクチャとメモリ不足が区別されず
  常に「メモリ不足」と表示されていた問題を修正。llama.cpp のロードエラーログを
  ネイティブ層で捕捉し、実際の失敗理由に応じたメッセージを表示
