# Nezumi AI v2.4.0 リリースノート

**リリース日:** 2026年9月8日

Nezumi AI v2.4.0 をリリースしました。

このバージョンでは、GGUF 推論基盤の llama.cpp 直結化と GPU バックエンド対応、推論エンジンのプロセス分離、Mini App の実行基盤と SDK、テレメトリの改善、Qwen3-TTS 音声合成を追加しました。

## 新機能

### llama.cpp と推論エンジン

* `rn-llama` を経由せず、本家 llama.cpp と JNI ブリッジで直接接続する構成へ移行
* llama.cpp のサブモジュール管理とビルド時のリビジョン表示に対応
* GGUF 推論で CPU、OpenCL、Vulkan の GPU バックエンドを選択可能にし、利用可否の検出とフォールバック通知を追加
* 端末の状態に応じて推論スレッド数の上限を動的に調整
* GGUF / LiteRT-LM 推論エンジンを別プロセスで実行する AIDL ベースの接続とリモートアダプターを追加
* `ai.unloadModel` API で、GGUF モデル使用後に LiteRT-LM のリソースを強制解放できるよう改善
* LiteRT-LM を 0.17.0 に更新

### Mini App と WebView

* Mini App Runner を追加し、インストール済み Mini App を WebView で実行可能に
* Mini App SDK の権限管理、初期化、RPC、HTTP サーバー連携を実装
* WebView の Document Start API とファイル選択に対応
* Mini App からモデルストレージへアクセスする際の制限とダウンロード API の利用を明確化
* Qwen3 Voice Studio の Mini App サンプルを追加
* Mini App から画像コンテンツチェッカーのモデルをダウンロードして推論できるサンプルを追加

### 音声とマルチモーダル推論

* Qwen3-TTS 音声合成とデバッグ用 UI を追加
* 音声履歴の管理と音声モデルの削除に対応
* コンテキストメーターが実際のトークン使用量を保持し、チャットセッションをまたいで正確な値を表示できるよう改善
* `kvUnified` パラメーターを追加し、画像処理を改善
* ONNX セッションのバックエンド選択と `createTensor` の処理を強化

### テレメトリとプライバシー

* オンデバイス推論でもクラウドモデルと同じ同意条件でテレメトリを送信可能に
* テレメトリの同意画面にクラッシュレポート、パフォーマンス計測、診断情報のカテゴリを追加
* ユーザー由来の内容がログへ出力されないよう改善
* Sentry DSN をリポジトリへ含めず、設定された場合だけテレメトリを初期化する構成に変更

## 不具合修正と改善

* シークレットモードでのセッション切り替え時に、画面とセッション状態が同期しない問題を修正
* GPU バックエンドが利用できない端末で、推論設定と通知が不整合になる問題を修正
* 推論エンジンの構造を整理し、モデルのロード・アンロードとストリーミング処理の安定性を改善
* Android WebView、OkHttp SSE、EncryptedSharedPreferences などの依存関係を更新
* `llama.rn` 依存を削除し、llama.cpp の直接統合へ移行
