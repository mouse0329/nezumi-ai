# Nezumi AI v2.3.0 リリースノート

**リリース日:** 2026年8月11日

Nezumi AI v2.3.0 をリリースしました。

このバージョンでは、クラウド推論エンジンへの対応、ツールコール表示の刷新、ドキュメント変換・Web取得ツールの追加、多言語対応の強化を中心に、多数の新機能追加、改善、不具合修正を行いました。

## 新機能

### クラウド連携

* LM Studio / Ollama / OpenAI互換APIのクラウド推論エンジンを追加
* クラウドモデル管理機能を実装
* クラウドプロバイダー参照とセッション管理機能を強化

### AIチャット・ツールコール

* インラインツールコールカードを実装
* `<tool_response>` タグのパースとUI統合に対応
* メモリへの明示的な保存を行う save_memory ツールを追加
* ページ取得ツールを実装（HTML取得結果をMarkdownに変換）

### ドキュメント

* Markdown⇔Word/Excel/PDFの変換ツールを実装
* モデルダウンロード前のライセンス確認とNOTICE整備

### 画像生成

* 画像生成確認ダイアログをComposeで実装（モデル・ステップ数の変更に対応）
* 進捗表示用カードとダークモード/ライトモードのカラーパレットを追加

### UI・多言語対応

* 言語選択機能を追加
* 添付オプションUIのデザインを刷新し、クリップボード画像ペースト処理を改善
* プリセット編集画面・添付オプション・ドロワーの各種ラベルを文字列リソース化

## 改善

* モデルラベル・モデルキャッシュ処理を最適化
* モデル/推論エンジン切り替え時の強制停止処理を改善し、リソース競合を防止
* ツール呼び出し結果を呼び出し順に保持し、吹き出し内のテキストとツールカードを統合
* テンプレートオプションのローカライズ文字列を整備

## 不具合修正

* LiteRT-LM外部インポートモデルのマルチモーダル入力処理を修正
* インラインツールコールカード表示の不具合を修正
* プリセット保存時のリグレッションを修正
* プリセット編集画面の「MCPを追加」ボタンを「新規/編集MCP」に変更
* ヘルプ内の更新履歴案内の誤りを修正（GitHub Releasesページの案内に訂正）

## 開発者向け

* PresetSettingsFragmentのリグレッションテストを追加
* ビルド成果物を更新し、mnn_sessionおよびmodel_configのデバッグ機能を強化
