# Nezumi AI v2.3.1 リリースノート

**リリース日:** 2026年8月16日

Nezumi AI v2.3.1 をリリースしました。

このバージョンでは、画像セーフティ機構の導入、Gemma 4 互換のツールコール処理強化、設定画面へのログ／ツール／ストレージ管理タブの追加、Noto Sans JP による日本語表示の改善を中心に、多数の新機能追加、改善、不具合修正を行いました。

## 新機能

### 画像セーフティ

* NSFL/NSFW を判定する画像セーフティ分類器（image-safety-classifier-xs）を実装
* Open NSFW と自社分類器による二段構えの画像セーフティガードを追加
* セーフティ判定結果を UI に反映し、ライセンス通知（NOTICE）を整備
* リリースビルドとデバッグビルドで異なるセーフティレイヤーフラグを適用

### 設定画面の拡張

* 設定に「ログ」タブを追加し、ツール呼び出し履歴と logcat をサブタブで閲覧可能に
* 常時ログタブをリリースビルドでも利用可能化
* 設定に「ツール」タブを追加し、Web 取得ツールの JS 実行可否と MCP サーバーを管理
* ストレージ管理セクションを追加し、モデル・キャッシュ・アプリ本体のストレージ使用量を可視化／削除

### ツールコール（Gemma 4 対応）

* GgufToolCallParser と GgufToolPromptBuilder を Gemma 4 互換に強化
* 複数フォーマットへのクロスフォーマット・フォールバックパースを実装（回帰テスト付き）
* ツール実行結果の保持・応答ロジックを改善
* Gemma4ThinkingParser を新規追加

### タイポグラフィ・多言語対応

* Noto Sans JP（可変フォント／スタティックフォント一式）を同梱し、日本語表示品質を向上
* NezumiTheme に日本語向けタイポグラフィスケールを整備
* ライセンス情報（OFL）と README を assets に同梱

### 画像生成

* ImageGenViewModel を幅・高さを独立に設定可能な形にリファクタリング
* メッセージアクションおよびパフォーマンス指標の表示レイアウトを刷新
* パフォーマンスインジケーター用のドロアブル／背景スタイルを追加
* mnn_session の実装を大幅に改善

### Web 取得ツール

* フォアグラウンド Activity 参照を管理する CurrentActivityHolder を実装
* WebFetchTool の WebView ハンドリングを強化し、JS 実行を制御可能に
* Ollama 推論エンジンの互換性を改善

## 改善

* ツール呼び出し履歴を保存する ToolCallHistoryDao / Entity / Repository を追加
* インラインツールコールカードのタップ処理を改善
* ErrorModalDialog をスクロール可能な内容に対応
* ChatFragment / activity レイアウトのタップハンドリングを改善
* MarkdownToPdfWriter の日本語フォント対応を強化
* モデル設定画面のダウンロード進捗・ファイル管理表示を改善
* ドロワーからログボタンを削除し、設定タブへ統合

## 不具合修正

* ツールコールパースにおける Gemma 4 系フォーマットの取りこぼしを修正
* Web 取得ツールでフォアグラウンド Activity が取得できない場合の挙動を修正
* 画像生成時の幅・高さ設定が連動してしまう問題を修正
* インラインツールコールカード表示の細部の不具合を修正

## 開発者向け

* GgufToolCallParserCrossFormatTest を追加し、クロスフォーマットのパース挙動を回帰テスト化
* 不要になったパッチファイル（0001-*.patch / 0002-settings-logs-tab-only.patch）を削除
* VOICEVOX_RESTORE.md を削除（検索エンジンのインデックス防止のため）
* アプリのバージョンを 2.3.0 から 2.3.1 に更新
