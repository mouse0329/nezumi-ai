# Nezumi AI v2.3.2 リリースノート

**リリース日:** 2026年8月30日

Nezumi AI v2.3.2 をリリースしました。

このバージョンでは、クラウド推論エンジンの KMP（Kotlin Multiplatform）共通化と Ollama ツールラウンドの大規模な回帰修正、スキル管理機能の新設、推奨モデルカタログとモデル管理 UI の刷新、クラッシュレポート機能の追加を中心に、多数の新機能追加、改善、不具合修正を行いました。

## 新機能

### クラウド推論エンジン（KMP 共通化）

* Claude / Gemini / LM Studio / Ollama / OpenAI の各推論エンジンを KMP の shared モジュールへ移行し、プラットフォーム共通の推論基盤として再実装
* OpenAI 互換 API と Ollama でストリーミング推論をサポート
* 画像エンコード・SSE 読み取り・API キー管理などを共通コードに集約し、Android 側はアダプタ層に整理

### スキル管理

* スキル管理機能を新規追加（プリセットへのスキル紐付け、ツールプロンプトへの注入）
* ユーザースキルのファイル管理（作成・読み込み・更新・削除の CRUD 操作）を実装
* スキルディレクトリに自動保存と新規フォルダ作成機能を追加
* ユーザースキルエントリのリネーム機能を追加

### モデル管理

* 推奨モデルカタログ（RecommendedModelCatalog）を追加し、おすすめ GGUF モデルの提示とセットアップウィザードでの案内を実装
* モデル管理 UI を刷新: 新しい FAB メニューと検索統合により、モデル追加・検索・管理の導線を整理
* モデル管理画面にクラウドモデルの登録・切り替えを統合

### チャット・メディア

* rnllama（GGUF エンジン）で音声・画像のマルチモーダル入力をサポート
* AI による画像生成の呼び出し前に確認ダイアログを表示する機能を追加
* MediaViewerDialog にファイル名表示とオーディオシーク機能を追加
* ツールコール完了時にドキュメント保存アクションを表示

### 安定性・品質

* 未捕捉例外を検知してダイアログ表示するクラッシュレポート機能（CrashReporter / CrashLogDialog）を追加
* CrashLogDialog を Compose へ移行し XML レイアウトを廃止
* ツールコールタグを安全に埋め込む ToolPayloadSanitizer を実装（回帰テスト付き）
* 構造化セーフティログを出力する SafetyLogFormatter を実装（ユニットテスト付き）
* Gemma4ThinkingParser と関連推論ユーティリティを実装
* 日本語・英語のローカライズ文字列とヘルプページを拡充

## 改善

### ダウンロード管理

* 画像生成モデルのダウンロード完了後、zip 展開フェーズに入ったことを進捗データに明示。従来は GB 級モデルの展開中（数十秒）も「ダウンロード中 100%」と表示されたまま無反応に見え、モデルがいつまでも追加されない不安を与える問題がありました
* DL タブのカードに「展開中（しばらくお待ちください）」ステータスを追加。展開中は進捗バーが不定（indeterminate）表示になり、処理が継続していることを視覚的に確認できます
* 展開中はダウンロード速度・残り時間の表示を非表示化（通信していないため誤解を防ぐ）

### その他

* 画像生成・設定画面の状態保存と UI 調整を改善
* KMP 移行に伴い ChatViewModel を分割し、PlatformProviders によるプラットフォーム依存処理の抽象化を導入
* ThinkingPromptStyleSpec / ToolCallTags のユニットテストを追加

## 不具合修正

### Ollama / クラウドツールラウンド（v2.3.1 回帰の修正）

* ツールコールとツール結果のロールが会話履歴で失われる問題を修正
* ツール結果を tool ロールの会話メッセージとして正しく返すよう修正
* ストリーム読み取り失敗を EOF として扱い応答が打ち切られる問題を修正
* 非終端ストリームチャンクに含まれるツールコールが失われる問題を修正
* ツールラウンドをまたぐとツール定義・Gemma4 ツールスキーマ・手動ツールプロンプトが失われる問題を修正
* 各推論ラウンドで新しいレスポンスチャネルを使用するよう修正
* Ollama KMP メッセージ構築とストリーム処理のコンパイル不整合を修正
* shared 推論基盤を現行のツールパーサー API に整合

### その他

* ツール結果ペイロードの JSON 変換を修正
* 画像生成時の設定値が画面遷移で失われる問題を修正

## ドキュメント

* パフォーマンス目標の初回推論時間を実測に基づき修正（2B: < 3秒 → < 10秒、4B: < 8秒 → < 20秒）。初回推論時間には GGUF 重みのメモリ読み込み時間が含まれており、2B モデル（約2GB）でも実際のメモリ帯域速度の制約から約10秒は必須であり、従来の目標値は物理的に達成不可能でした
* 開発ストーリーに OpenCL ノイズ問題の調査記録を追加。画像生成（OpenCL 実行）で「中央だけ色がまとまり周辺がランダムノイズ」になる問題の真因が、MNN の OpenCL バックエンド（low memory モード）が int8 量子化重みを int4 として解釈し、読み込みビット幅が半分にズレてテンソル後半が未初期化メモリで計算されていたことである、と特定された経緯をまとめています
* KMP 移行レポート、UI Compose 移行計画、iOS 移行計画のドキュメントを追加
* Markdown ドキュメント変換ツールのコメント・ドキュメントを整備

## 開発者向け

* `ModelDownloadWorker` に `KEY_IMAGE_MODEL_IS_EXTRACTING` 進捗キーを追加（zip 展開開始時に進捗データとフォアグラウンド通知を更新）
* shared/build ディレクトリの追跡を停止しビルド成果物をリポジトリから除外
