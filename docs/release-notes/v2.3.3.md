# Nezumi AI v2.3.3 リリースノート

**リリース日:** 2026年8月31日

Nezumi AI v2.3.3 をリリースしました。

このバージョンでは、GGUF のチャットテンプレート処理と思考タグ解析の強化、ダウンロード済みモデルの登録・キャッシュ管理の改善、モデル削除後のプリセット復元、OpenCL の利用可否に応じた GPU 設定制御を行いました。

## 新機能

### OpenCL と GPU 設定

* OpenCL の利用可否を実行環境で確認する `OpenClAvailability` を追加
* OpenCL が利用できない端末で GPU レイヤー数を適切に扱えるよう、推論設定と設定画面の連携を改善
* OpenCL の状態を設定画面に表示するための日本語・英語リソースを追加

### GGUF チャットテンプレートと推論

* GGUF メタデータから `tokenizer.chat_template` を読み取り、キャッシュする処理を追加
* 標準の `<think>...</think>` 形式に加え、Qwen 系の `<|think|>...<|/think|>` 形式を表示用解析で扱えるよう改善
* LiteRT-LM の構造化プロンプトを追加し、テンプレートの二重適用を防止
* Gemma 4 の思考出力解析と、プロンプトテンプレートの Jinja 構文検証を強化
* 推論エンジン間でプロンプト構築とストリーム処理の責務を整理

### モデル管理

* ダウンロード完了後のモデル登録処理とモデルキャッシュの無効化を実装
* モデル管理画面で、登録済みモデルの更新・削除状態をより正確に反映

## 不具合修正

* モデル削除後に、プリセットが存在しないモデルを選択したままになる問題を修正
* モデル削除後のチャット画面とモデル設定画面の選択状態を同期
* プリセットの再構築時に利用可能なモデルだけを参照するよう修正

## テスト

* Gemma 4 思考タグ解析、LiteRT 構造化プロンプト、Jinja テンプレート検証に関するテストを追加・更新
